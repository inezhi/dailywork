# 时序 · Dailywork — 产品需求文档（PRD v0.2.0）

状态：已实现基线 · 更新：2026-10-27 · 归档：[飞书 02 PRD](https://my.feishu.cn/docx/QprvdtuRPoDIfIxkAqAcjHWSncd)

## 1. 一句话

一款跑在 Mac 上的个人工作台，把**任务、时间、专注与知识**放进同一个闭环：捕获 → 规划 → 执行 → 复盘 → 洞察。

## 2. 用户与场景

| 用户 | 场景 | 成功的样子 |
|---|---|---|
| 独立开发者 / 设计师 | 早上决定今天做什么；在多个项目间切换 | 打开应用 30 秒内知道下一步；不被几十个任务淹没 |
| 内容 / 研究者 | 随手记下想法，写作时串起来 | 碎片速记能变成任务或文档；文档与任务互链 |
| 自由职业者 | 排期、估算、对交付负责 | 日历 / 时间轴与容量一致；逾期与偏差可见 |
| 手机端用户 | 沙发上快速记录、查看今天 | 连接同一个服务端后，添加到主屏幕即可用 |

不是面向团队协作的产品：0.2.0 不做组织与权限、实时协同、公网部署；同一安装可创建多个个人账户。

## 3. 核心闭环

1. **捕获**：收件箱 / 速记（支持 `#标签`），不打断手上的事。
2. **规划**：任务进入项目与日期；今天页按真实容量安排；看板呈现流动。
3. **执行**：番茄专注与任务联动，自动累计实际投入。
4. **复盘**：周复盘数据（完成、专注、项目贡献）与仪表盘洞察。
5. **洞察**：KPI、趋势、需要关注列表；不制造焦虑，只给下一步。

## 4. 功能范围与验收标准

### 4.1 任务核心

- 任务字段：标题、备注、状态（收件箱 / 下一步 / 进行中 / 等待中 / 受阻 / 已完成）、优先级、项目、计划日期与时间、截止日期、预估分钟、实际分钟、标签、子任务（一层）。
- 支持快速添加：`#标签`、`!1`–`!4` 优先级、`@today` / `@tomorrow` / `@YYYY-MM-DD`。
- 乐观并发：可选 `expectedVersion`，冲突返回 `VERSION_CONFLICT`。
- 所有变更写入 `op_log`，支持幂等 `opId`；任务创建/更新/完成/删除可通过「撤销上一步」恢复（before 快照）。
- 验收：创建 / 更新 / 完成 / 重新打开 / 删除 / 移动在 UI 与 CLI 返回同一信封；重启后数据仍在。

### 4.2 视图

- **今天**：今日容量条、专注环、进行中 / 下一步 / 等待 / 受阻分组、今天到期、逾期提示、今日完成折叠。
- **全部任务**：状态筛选、搜索、项目筛选、按计划 / 截止 / 优先级 / 创建时间排序；支持「列表 / 四象限」切换（重要紧急矩阵）。
- **看板**：下一步 / 进行中 / 等待中 / 受阻四列，完成列可展开；拖拽改状态与排序；键盘可拖动（dnd-kit 键盘传感器）。
- **四象限 / 日历 / 时间轴**：四象限拖拽调整优先级与截止日期；月/周日历与时间轴拖拽改期。
- **日历**：月 / 周 / 日；事件按空间着色；当日议程、容量与快速添加。
- **时间轴**：28 天甘特，计划与截止构成时间带，今天高亮。
- 验收：断网仍可浏览已加载数据；所有视图点击任务打开同一详情抽屉。

### 4.3 项目、空间与模板

- 空间分组（颜色、图标、归档）；项目（颜色、状态、起止、描述、验收标准、交付成果）。
- 项目工作台展示总数 / 完成 / 未完成 / 进度、任务分组、交付成果勾选、最近操作记录。
- 模板：项目页可把当前任务保存为模板，并一键应用；支持删除（API）。
- 验收：归档项目不丢任务；删除项目任务变为未归类。

### 4.4 速记与收件箱

- flomo 式卡片：内容、`#标签`、置顶、颜色、时间；支持搜索与标签筛选。
- 一键转任务（保留内容为备注、标签带入任务）；速记可添加图片/PDF 附件。
- 收件箱聚合未整理任务与未转换速记，支持安排到今天、转任务、删除。
- 验收：转任务后速记显示「已转任务」且不可重复转换（`CONFLICT`）。

### 4.5 计划与专注

- 每日容量（默认 300 分钟，可逐日覆盖），今天页展示「已安排 / 容量」。
- 每日例程：按星期重复的小节奏，显示在今天页；可在设置中启用/停用。
- 专注：15 / 25 / 45 / 60 分钟或自定义；同一时刻仅一个进行中会话；结束后累计任务实际分钟；取消不计入任务。
- 每日收尾：查看完成与未完成、写一句日注、把未完成的任务一键移到明天。
- 专注环出现在今天页、专注页、顶栏计时与仪表盘。
- 验收：刷新页面后计时从服务端恢复；关闭再打开不丢会话（6 小时内）。

### 4.6 文档

- 块编辑器（标题、列表、待办、引用、代码块、表格、图片、链接、高亮）；选区 AI 菜单（润色 / 续写 / 摘要 / 翻译 / 提取任务）。
- 文档树（父子）、挂载空间 / 项目 / 任务、反向链接（`task://` / `project://` / `document://`）。
- 自动保存：正文 850ms 防抖；标题 450ms；首行自动成为标题。
- 图片上传：入 `blobs`（BLOB + sha256 去重 + 320px WebP 缩略图）。
- 验收：粘贴/插入图片后重启仍可见；文档标题与正文搜索可命中。

### 4.7 仪表盘

- KPI：完成、完成率、专注时长、逾期、准时率、预估偏差；本周复盘弹窗（每日完成、项目贡献、自动亮点）。
- 30 天趋势（完成柱 + 专注线）、项目推进、状态分布、空间负载、洞察卡、需要关注。
- 范围切换 7 / 30 / 90 天 / 12 周。
- 验收：完成一个任务后，KPI 与趋势在当前范围内更新。

### 4.8 搜索与命令面板

- `⌘K` 全局搜索任务、速记、文档、项目；空查询显示导航与「新建任务」。
- 方向键 + Enter 打开；Esc 关闭。
- 验收：输入关键词 200ms 内出结果；点击任务打开详情。

### 4.9 AI 助理

- 供应商：DeepSeek 默认、任意 OpenAI 兼容端点（Base URL + Key + 模型）；密钥 AES-256-GCM 加密。
- 对话可调用 ops 工具（`task.*`、`today.get`、`search.all` 等）；只读工具自动执行；变更需开启「允许执行变更」；破坏性操作永不由 AI 自行确认。
- 流式回复（SSE delta）、对话历史侧栏、工具执行轨迹。
- 上下文入口：任务抽屉「AI 拆解」、文档工具栏「AI 润色 / 摘要」、周复盘「让 AI 帮我复盘」。
- 工具轨迹在消息下以 chip 展示（已执行 / 待确认 / 失败）。
- 验收：未配置供应商时引导去设置；关闭 AI 后入口禁用；工具调用写入 `op_log`（actor=ai）。

### 4.10 CLI / MCP

- `daily` 覆盖全部暴露的 ops；`--json` 输出完整信封；退出码稳定。
- `daily mcp serve` 以 stdio MCP 提供 70+ 工具（名称 `task_create` 等），带 readOnly / destructive 注解。
- 验收：`daily task create "x" --json` 与 UI 创建等价；MCP `tools/list` 可被客户端解析。

### 4.11 备份与迁移

- 导出 `.dailywork`（账户数据库 + 图片 + manifest）；账户备份不包含 AI 密钥解密根，恢复后需重新填写；导入先校验完整性、schema 版本，暂存后重启原子替换；导入前自动备份当前库。
- 验收：导出 → 新建空目录导入 → 任务 / 文档 / 图片数量一致。

### 4.12 局域网与移动端

- Mac 服务监听局域网；设置中展示地址与 6 位配对码；设备配对后写入 HttpOnly cookie。
- 手机 / 平板响应式：底部 Tab（今天 / 日历 / 看板 / 文档 / 仪表盘）、全屏抽屉、44px 触控目标、速记与新建入口。
- PWA manifest + 图标；可选 HTTPS：在设置中生成自签名证书（含当前 LAN IP），重启后固定端口 47822 提供 HTTPS，信任证书后 Service Worker 可离线缓存。HTTP 下仍可访问，但无离线缓存（浏览器安全上下文限制）。
- 验收：iPhone Safari 配对后可创建 / 完成任务；整机重启后配对仍有效（服务 token 持久化）；竖屏布局无横向滚动。

### 4.13 账户

- 注册：用户名 + 唯一邮箱 + 密码（至少 8 位，需同时包含字母和数字）+ 图片验证码；每个账户拥有独立的任务、项目、文档、速记、专注、设置与 AI 供应商。
- 登录：用户名 + 密码；同一用户名连续失败 3 次后要求图片验证码；会话 cookie HttpOnly、SameSite=Lax，30 天有效。
- 修改密码：校验当前密码；新密码同样要求至少 8 位且含字母和数字；修改后其他设备上的会话失效，当前会话保留。
- 头像：可上传 PNG / JPEG / WebP / GIF（≤5MB）或移除；**默认头像使用用户名首字母**。
- CLI / MCP 通过服务令牌以首个账户身份工作；局域网配对默认绑定首个账户。
- 验收：注册后进入工作台；两个账户互相看不到对方任务；退出后重新登录数据仍在；修改密码后旧密码失效。

### 4.14 版本记录

- 设置 → 关于 → 版本记录列出每个版本的日期、标题与新增/改进/修复内容；首次发布起保留历史。
- 每次发布同步更新应用内记录、`docs/04-process/CHANGELOG.md` 与安装包版本号。
- 验收：打开版本记录可以看到当前版本与至少一个历史版本。

### 4.15 设置与主题

- 主题模式（浅 / 深 / 跟随系统）、强调色预设与任意取色、四个语义色、中性色温度（暖 / 中性 / 冷）、密度（舒适 / 紧凑）；默认主题为经典蓝（#1677FF + 冷白画布）。
- 通用：每周起始日、默认专注、默认容量、减少动效、AI 开关、局域网开关。
- 数据：数据目录、备份导出 / 导入、CLI 示例；关于页展示版本与飞书文档入口。
- 验收：改强调色后所有主按钮、进度、选中态即时变化；深色模式对比度可读。

## 5. 非目标（v0.2.0）

团队角色与权限 / 实时协作光标；iOS / Android 原生客户端；Windows / Linux 构建；Todoist / Flomo 双向同步；公网托管；历史数据导入器；任何云同步。

## 6. 指标

- 打开到「知道下一步」≤ 30 秒。
- 今日页一次创建任务 ≤ 3 次交互（输入 + Enter）。
- 1 万任务时列表首屏 ≤ 300ms。
- 零云端依赖：断网时除 AI 外全部可用。

## 7. 约束与风险

- macOS 26+、Node 24+（Electron 内置）；个人使用 ad-hoc 签名，更新为手动下载 dmg。
- 数据由你掌控：磁盘损坏 / 误删风险由每日快照与手动导出兜底。
- AI 会把上下文发送到用户配置的供应商；按空间禁用 AI 为后续增强。
- 局域网 HTTP 下 PWA 离线缓存不可用；HTTPS 证书已在 0.2.0 提供（移动端需手动信任）。
