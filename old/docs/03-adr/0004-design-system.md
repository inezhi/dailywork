# ADR-0004：设计系统与主题

状态：已接受 · 2026-10-27

## 背景

设计要求高：初版参考暖米白 + 陶土橙，2026-10-27 将默认主题切换为经典蓝（冷白画布 + #1677FF 强调色）；支持用户自定义强调色/语义色/中性色温，避免「AI 生成感」。

## 决策

- 设计 tokens 存 CSS 变量；浅/深色为两套定值，而非简单反色；中性色温通过 `data-neutral` 覆盖画布组；密度通过 `data-density` 调整行高。
- 组件不直接使用十六进制色值；一律引用 token。强调色在运行时按亮度自动选择前景色。
- 半径按层级、阴影极浅、1px 边框分层；统一 Lucide 图标；动效 120–200ms 且尊重 reduced-motion。
- 签名元素只有「专注环」，其余界面克制。
- 设计画廊 `/design` 作为活文档；高保真稿在 `design/mockups`。

## 结果

- 主题编辑即时生效、可回归测试（对比度/变量）。
- 避免了 shadcn 默认观感；代价是需要维护一套自定义 CSS。
