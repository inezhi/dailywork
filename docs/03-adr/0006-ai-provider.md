# ADR-0006：AI 供应商与护栏

状态：已接受 · 2026-10-27

## 背景

用户自备 Key；默认 DeepSeek，同时支持任意 OpenAI 兼容端点（含本地 Ollama）。AI 需要读取本地数据并执行操作，必须可控。

## 决策

- 供应商配置存 `ai_providers`；API Key 用 AES-256-GCM 加密（密钥文件 0600）；不进入日志/备份以外的任何地方。
- 对话与消息存 SQLite；每次请求带系统提示（日期、规则）与当前上下文（任务/项目/文档/周复盘）。
- 工具 = ops 目录（`exposure.ai`），JSON Schema 由 zod 生成；工具循环最多 5 轮，结果截断 6000 字符。
- 只读工具自动执行；非破坏性变更需 `confirmTools`（界面「允许执行变更」）；破坏性操作恒返回 `CONFIRM_REQUIRED`。
- 非流式请求（90s 超时）；AI 关闭时返回 `AI_DISABLED`。

## 结果

- 用户可完全掌控 Key 与数据；AI 不会被允许静默删除数据。
- 流式输出、按空间禁用 AI、对话式确认卡片列为后续增强。
